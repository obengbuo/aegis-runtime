Changelog & roadmap

What shipped, and what's next.

The public API, everything you get from from aegis import …, is stable as of v0.2.0. The full history is on GitHub.

Unreleased on main

  • Rule 7 now classifies argument value types and closes the collection bypass. Lists are matched one element at a time, empty lists are denied, unconstrained lists are denied, and types the engine can't reason about are refused. Adds the allow_any waiver. Write-up.
  • spec_hash on every governed call, including allowed ones, not only refusals.
  • Tool content redacted in every audit field, whatever the inspection mode.
  • The OWASP MCP Top 10 mapping was corrected in twelve places before publishing.

v0.2.0 15 Sep 2026

  • Control-plane shipper: a bounded queue, batching and fail-open transport. HTTP failures are classified instead of every one being retried.
  • Optional run_id on load_spec / propose_spec, so the opening record joins its run.
  • call_id and ts on all six lifecycle audit records. response_inspection_mode is recorded on detections.
  • End-to-end demo covering the proposer, enforcement, shipper and control plane.
  • Integration guide rewritten for a general audience, with the path-representation constraint and verified examples.

v0.1.1 23 Jul 2026

  • User-facing README, a runnable example and a troubleshooting guide for the public release.

v0.1.0 16 Jul 2026

  • First public release: wrap_toolset, the capability-spec engine (rules 1–9), the LLM proposer, intercepts, response inspection, JSONL audit log and OTLP export.

Roadmap

Next up

  • Wire server fingerprinting into enforcementCall drift detection from wrap_toolset, write an audit record when drift is found, and decide whether drift should block a run. Also fix the stored baseline being overwritten when drift is detected.
  • Hash chain over the audit sequenceMake the trail tamper-evident, not just append-only by convention.
  • Expanded detection patternsMore credential shapes for response inspection.
  • Container imageA packaged runtime for the library.
  • More MCP server integrationsServer-specific guidance and tested specs.
