About

Built in public, checked against the code.

Aegis began from one question: once an agent is authenticated, what stops it doing something its user never asked for? The answer it settled on is a frozen, per-task capability spec, enforced by code that never reads the attacker's text as instructions.

STAGE

Pre-production. v0.2.0 is shipped, public and pip-installable. The library has 218 tests and the control plane has 317.

BUILT FOR

Platform and security engineers running agents with real tool access, especially where "prove what the agent did" is a requirement, not a nice-to-have.

LICENCE

MIT, both repositories. No hosted offering, no telemetry, nothing that phones home.

How it's built

Write the claim down, then check it.

Each guarantee on this site was first written down as a specific claim, then checked against the code rather than against memory. That habit has caught a runnable example that didn't run, an injection scenario documented as firing a rule it never fired, a false correlation-ID claim, twelve overstated claims in the OWASP mapping, and two capability-scoping bypasses.

The rule for this site follows from that. If a page here and the repository disagree, the repository wins. Please report the mismatch.
