TRY THIS

Break the batch

Run Batch smuggling, then delete the must_match_one_of list under paths. The call is still denied, now with rule-7-unconstrained-collection. That's the fix described in the bypass write-up.

TRY THIS

Waive it out loud

Replace the list with allow_any: true. Now anything is allowed, but the record says rule-7-bypassed-allow-any, so the waiver shows up in a query and doesn't pass for a clean check.

TRY THIS

Weaken the posture

Set deny_all_others: false. The spec is rejected until the task text includes deny_all_others=false. Add it, fire Unlisted server, and the call is allowed but flagged rule-1-bypassed-weak-posture.

The playground ports Aegis's evaluation rules exactly. Small differences are possible where JSON and Python types differ. For example, JSON can't tell 1.0 from 1, and it has no tuples or sets. For production decisions, the Python engine in aegis/policy.py is the source of truth.
